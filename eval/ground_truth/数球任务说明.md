## 二、怎么操作（4 步）

1. 用 **PotPlayer** 或 **VLC** 打开视频（别用网页播放器）；
2. 从头看一遍，心里有个数：这段大概有几次投篮；
3. 再回头看第二遍，看到有人投篮就**暂停**，看进度条上的**秒数**（精确到 0.5 秒就行）；
4. 在下面的表格里加一行。

**逐帧小技巧**：暂停后按 `E`（VLC）或 `F`（PotPlayer）可以一帧一帧前进，用来确认球到底进没进。

## 三、判定规则（很重要，必须统一）

### ✅ 什么算"一次出手"（记一行）
- 球从手里出去、并且是**朝篮筐投**的：罚球、跳投、上篮、**补篮**都算；
- 被犯规或被封盖但**球还是投出去了** → 也算一次出手，结果填 `miss` 或 `unknown`；
- **补篮最容易漏**：抢到篮板后马上再投，要**单独记一行**。

### ❌ 什么不算
- 传球、运球、抢篮板、发球、假动作；
- 球离手但明显是横向传球（不是朝篮筐）。

### 🎯 怎么算"进"
| 情况 | 怎么填 |
|---|---|
| 球从上方穿过篮筐、向下离开（含打板进、空心进） | `make` |
| 球在筐上弹了几下**最后掉进网里** | `make` |
| 球在筐上弹了**最后弹出去** | `miss` |
| 球卡在篮筐上 | `unknown` |
| 画面遮挡 / 球出画 / 看不清有没有穿网 | **`unknown`（不要猜！）** |

> ⚠️ 看不清就写 `unknown`。写错比写"不知道"危害更大，因为我要用它来算软件的准确率。

## 四、填这张表（每个视频一张表）

**列的含义：**

| 列名 | 填什么 | 必须填吗 |
|---|---|---|
| `video` | 视频文件名（不带后缀也行） | ✅ 必填 |
| `shot_no` | 第几次投篮，从 1 开始编号 | ✅ 必填 |
| `release_s` | **球离手那一瞬间**的秒数 | ✅ 必填 |
| `rim_s` | 球到达/穿过篮筐的秒数，看不清就留空 | 可选 |
| `result` | `make`（进）/ `miss`（没进）/ `unknown`（看不清） | ✅ 必填 |
| `shooter` | 谁投的，看不清就留空（如"左边白衣服"） | 可选 |
| `shot_type` | 罚球 / 跳投 / 上篮 / 补篮 / 被封盖 | 可选 |
| `note` | 备注（如"砸后框弹出"） | 可选 |

**示例（照这个样子填）：**
```
video,shot_no,release_s,rim_s,result,shooter,shot_type,note
dairy_courts,1,6.0,6.9,make,,跳投,
dairy_courts,2,16.4,17.1,make,,跳投,
dairy_courts,3,25.4,26.0,make,,跳投,
nathan_freethrow,1,6.5,6.7,make,,罚球,第一球
nathan_freethrow,2,14.2,,miss,,罚球,砸后框弹出
nathan_freethrow,3,17.2,,unknown,,罚球,被挡住看不清
```

**如果不想用 Excel，直接在纸上/微信里按这个格式写也行**，发我文字我帮你转。

## 改了什么

### 第 1、5 条：去重
* `web/pages/upload.js`：删掉「篮筐标点」行里那个多余的「标球场」按钮 —— 现在只有
  「篮筐标点」管篮筐、「球场标定」管球场，各一处。

  `group` 渲染（**首页 / 分析流程 / 结果与产出**），顶栏只留品牌、后端状态与「重新探测」。

### 第 2 条：进球标注退出主流程（纠错入口前移）
* 删掉「进球标注(可选)」输入框。后端 `basket_labels` 参数保留，脚本/命令行仍可用。

  要留样本去「训练标注」页** —— 这就是用户说的"分析完以后加一个报错的选项"，
  功能本来就有（复核页的「判为命中/判为未中」），只是以前没有指路。

### 第 3 条：随机种子退出界面
* 删掉「随机种子 seed」输入框；请求体也不再发 `seed`。
* 「载入演示数据（离线可用）」改名 **「载入离线样例（合成比赛，仅供界面演示）」** ——
  它加载的是仓库里的合成产物（**不生成假视频**），改名是为了别让人误以为那是分析结果。
* 合成数据的唯一入口保留在命令行：`python -m aihoop.cli demo --seed 7 --duration 600 --out out/demo`。

### 第 4 条：新增首页（主界面）
* 新增 `web/pages/home.js`（+ `web/styles.css` 的 `.home-card*` 样式），四块内容：

  3. **各模块卡片**：直接由 `window.MENUS` 渲染（含一句"这个模块能看什么"），点卡片跳转。
  4. **最近任务**：`GET /api/jobs` 取最近 5 条，点「查看」直接装载产物并跳到结果页。
* 菜单表加 `group` 字段并把首页排第一；`app.js` 默认路由改成 `home`（含 hash 兜底）。

# 追加：第 6 条意见 —— 篮筐标点只要中心（2026-09-27 同日）

> 用户原话："篮筐标点那可以把未标点删了，标篮筐中心就挺准的吧可以不需要再标上下左右四个点了"

## 改了什么

* **删掉「未标点（走自动检测）」标签**：没标点时不显示任何徽章（没有徽章＝还没标）。
* **必点项只剩「篮筐中心」**：`markItems` 从 5 项缩到 1 项；四边（左/右缘、上/下沿）
  收进「可选：量一下筐宽」的一排小按钮，不点也能保存、也能分析。
* 标点对话框的提示改了：中心点完后是"可以直接保存"，并说明"没量筐宽也没关系，
  半径会由检测器量"。
* 保存时如果没量到宽度，前端**交 0 出去**（= 不知道），不再编一个"画面宽 2%"的假半径。

## 过程中发现并修掉的一个真问题（这一步很关键）

**第一版实现是错的，实测抓住了**：我一开始让后端"只标中心时"用检测器的半径，
但**仍把筐固定成标点那一帧的一个点**。结果在 nathan（手持、镜头在动）上：

| 方案 | 结果 |
| --- | --- |
| 完整标点 / 自动检测（基线） | 3 个进球（4.91 / 15.55 / 23.66）+ 2.64s 贴筐 + 3 未知 |
| 只标中心 → **固定成一个点** | ❌ **只剩 1 个进球**（4.91 与 15.55 被误判成"贴筐掠过"） |
| 只标中心 → **当提示、筐位仍逐帧跟踪** | ✅ **与基线逐条一致**（3 个进球、81 个筐采样、稳健漂移 31.1px） |

原因：固定成一个点等于声称"整段素材篮筐不动"。这段素材镜头在动，t=7.3s 的真实筐心
比标点那一帧偏了 20 多像素，偏移量算错 0.6×rx，真进球就被判成贴筐。

**所以最终实现**（`src/aihoop/sources.py::_visual_attempts`）：

* 标了中心 **且** 至少一侧边缘（能算出 rx）→ 直接采信、跳过检测器
  （固定机位下最可靠；fixedcam 就是这样拿到 3/3）。
* **只标了中心** → 中心作为**初始位置提示**交给检测器（`detect_hoop_track(hint=...)`），
  筐位逐帧跟踪、半径取跟踪结果中值；元数据里记
  `visual_hoop_source="manual_center+hint(tracked)"` 与 `manual_hoop_radius`（含来源与说明）。

## 验证

* 只标中心跑 nathan（真后端、真视频）：`manual_hoop_radius={"rx":30.6,"ry":9.5,"source":"detector_track"}`、
  `visual_hoop_source="manual_center+hint(tracked)"`、81 个筐采样、结果与基线**逐条一致**。
* fixedcam（完整标点那条路）回归：**3 球全中、0 未知**，与之前一致。
* `tests/test_ui_home.js` 扩到 **27 条断言**：必点项只剩中心、可选四边仍在、
  没有「未标点」文案、只点中心时 `rx=0`（不再编假半径）、中心+左缘时 `rx` 等于量出来的距离、
  源码里不再有 `rx = 0.02` 那行假精度默认值。
* 完整门禁全部通过；前端缓存版本号 `?v=33` → **`?v=34`**。

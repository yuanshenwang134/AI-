# 篮筐身份修正与 nathan 目视检查

## 修正

模型篮筐路径此前每个采样帧独立选置信度最大框，未沿用上一目标身份。本轮新增 `_select_rim_candidate`：初次按置信度；之后按位置距离、宽高比例筛选，在合格候选中选最近者。无合格候选则跳过，不用远处高置信度框替代。保留实际检测置信度。

成功输出的 HoopTrack 增加 identity_trace：每个采样时刻的候选、选中框与原因。已有漂移闸门保持，报错标题改为“篮筐轨迹不稳定”，不再仅凭篮筐漂移断言镜头在移动。

局限：首次仍可能锁错；附近相似目标仍可能混淆；没有加入相机运动补偿、外观重识别或切镜重锁。检测失败时 trace 尚不会随 RuntimeError 自动保存到 raw_track。筛选会改变轨迹，需外部完整推理复核 day、night 及四段基线，不能声称真实召回改善或仍零误报。

新增 8 项选择/序列化检查；完整 check_all.py 全部通过（14 个汇总组）。没有执行视频模型推理。

# 旧引擎接入新版复盘

## 本轮交付

新版应用和复盘界面保留。新建视频任务默认 `shot_engine=legacy`、`score_policy=court`：逐帧选球/筐→建立出手→判命中/未中/未知→新版统计、复核与报告。
用户不需要重复框球训练，也不需要单独启动旧版网页。

移入的是独立模块 `src/aihoop/legacy_shots/`，不依赖 `_tmp/hoopai_from_bundle` 路径。旧联合检测权重仍从新版既有 ball_weights 路径加载。球/筐联合推理每帧只调用一次，使用旧版 640 输入、conf=0.25、iou=0.5；原球员检测/分队、标定、战术仍用新版流程。

## 口径和保护

- 所有状态机事件进入候选列表，未知 made=null，不自动计分。
- 预测点不建立新出手，不确认命中；遮挡兜底仍默认关闭，开启也只能给建议。
- 切镜时以未知结束未决事件，清空球/筐状态，不跨镜头拼接穿筐。
- 完整手标筐保持固定几何；仅中心标点用于初次选筐，之后跟踪检测框，不编半径。
- 找不到筐或真实球时记录无法判断的原因，不静默切回另一套算法。
- 只把已识别出手人脚下投到球场。没有可信位置时保留占位和估计标签，不用旧版像素距离猜三分。
- 无法归队的进球仍显示命中，但不编造一队得分。
- 状态机已有未中/未知，不再调用旧的近筐候选补充，避免重复出手。
- 复核片段覆盖出手至判定收尾，不只截离手后 1.5 秒。

默认场上口径不让比分牌改写结果，比分牌仍可作为参考。显式选择 auto/scoreboard 时保留原比分牌优先机制，不声称这两种模式会找全场上全部出手。

## 对照和诊断

API 可显式给 `shot_engine=geometry` 保留上一套视觉判据作对照。geometry 的推理参数保持原值。
每次任务保存引擎版本、完整有效状态机配置、权重 SHA256 和同次运行选中的逐帧球/筐/人框；精度不截断，预测框明确标记。默认复盘页显示“逐次出手引擎”。

离线回放：
```
E:\python\python.exe -B scripts\replay_legacy_shots.py --raw out\<新任务>\raw_track.json --out out\<独立文件>.json
```
输入输出不得是同一路径。返回 exact_match=true 表示重放事件与保存事件相同，不是人工准确率。

## 验证与边界

新增检查覆盖：真实穿越、侧边落球、无球、预测空档、切镜、中心提示、完整手标、三态与建议到新版统计、未知队别不计分、默认/对照接线、片段覆盖判定时刻、模拟视频逐帧检测结果通过完整 VideoSource.run、API 默认值与非法引擎拒绝。
保留旧版穿筐几何回归。完整门禁通过情况以本轮运行日志为准。

本轮没有跑 GPU 真实视频回归；历史任务没有重建，已打开的旧任务不会自动变成新结果。当前服务如已运行需重新加载后端，新建任务才能启用。
移植不等于已证明恢复 fixedcam 的 7/3：球员归因和切镜机制有差别，出手建立/近筐传球/超时未中/篮筐换目标仍需实测。下一步按已有人工真值先复检 fixedcam、nathan、dairy，再验日夜室外和比赛片段。

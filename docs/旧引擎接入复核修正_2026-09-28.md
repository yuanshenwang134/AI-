# 旧引擎接入复核修正（2026-09-28）

## 已实施

- 剪辑真实调用优先使用 Shot.clip_start/clip_end，旧产物 0/0 回退原窗口，按视频长度截断。新增测试检查传入切片函数的范围，不只检查字段。
- decision_t（判定收尾）与 release_source 经 Attempt → Shot → timeline 贯通；timeline 也输出片段范围。总览缺 crossing_t 时提供“看判定收尾”入口。原视频仍可自由播放；没有实现进度条选区播放。
- 进入筐口但没有实测向下穿越证据时，离开/超时记 unknown；实测、预测、无球三个收尾路径一致。不把缺证据自动升级成命中。
- 类内 miss_timeout_s / rim_readopt_far_frames 回退统一为 3.5 / 6。
- 热重载递归监听子目录，并修复先杀进程再等待任务的顺序；状态查询失败时延后重载，不强制超时杀任务。改动生效需要当前启动器本身下次重新启动。
- 位置未知的占位点不进入后端热区或前端兜底图；输出距离为 null、区域为位置未知。总览说明默认两分是暂计，需复核分值；不改变现有暂计比分政策。
- 新增实验 API 参数 legacy_center_lock（默认 false）：有人工中心时，以首次确认筐宽的三倍约束后续候选，切镜后也不接受远处另一筐。无尺寸提示不伪造静态筐。该方案仅适合固定机位，尚不能跟随大范围摇镜。

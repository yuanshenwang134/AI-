## 三、真进球为什么还只是"未知"：两条只差一点的判据

用新产物（`out\5c3f0020f46d`）全量插桩，第三次出手（release 15.22）的收尾状态：

```
真实观测：16.48 (1041,282) → 16.52 (1043,288) → 16.55 (1043,295) → 16.58 (1044,306)
          → 16.62 (1047,318) → … → 16.75 (1050,370)
每一条：hd = 0.8~7px（在筐口内 ✓）、筐底以下 ✓、比上一条更低（正在下降 ✓）
判定：uncertain @16.75，evidence=insufficient_evidence，crossing_t=None
```

两条判据各差一点点：

1. **没有测到"向下穿越筐心"**：唯一跨过筐心高度的真实观测对是
   `15.95 (y=226.6) → 16.48 (y=282.3)`，间隔 **0.53s**，而新增的连续性要求是
   `t - prev_real_t <= ball_recent_s(0.5s)` → 差 **0.03s** 被判不连续 → `crossing_t=None`。
   （中间 15.98–16.12 是预测帧、16.15–16.45 完全丢球，正是"球穿网瞬间被遮挡"。）
2. **`entered_t` 记早，0.9s 命中窗口提前到期**：`inside_rim` 的默认判据是
   `hd < 1.0×筐宽` 且 `by ∈ [rim.top−1×h, rim.bottom+1×h]`（`scorer.py:191-192,387-391`），
   球还在**接近阶段**（离筐心 80px、比筐心高 40px）就被判 "entered" → `entered_t≈15.45`，
   窗口到 **16.35** 到期；而球第一次"筐口内 + 筐底以下"的真实观测在 **16.48** → 差 **0.13s**。

**建议方向（都未验证，仅供参考）**：
- 给 crossing 的插值单独放宽相邻间隔（例如 0.6~0.7s），与"最近证据"语义分开；
- 用"球在筐口内且筐底以下"的**首次观测**重锚命中窗口，而不是用接近阶段的 `entered_t`；
- 或启用 `make_allow_occluded_entry`（本球满足其条件：entered + 之后在筐口内、筐底以下、
  下降），但目前窗口从 15.45 起算所以失效 —— 这条开关当年因"夜间多罚球出现假进球"被降级，
  要启用必须跑五段回归（**本轮六段基线已就位，可直接对照**）。

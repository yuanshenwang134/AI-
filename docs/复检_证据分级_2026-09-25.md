### 2.4 他们修掉的两处（我逐行核过代码）

1. **拟合分支不再绕过门槛**：现在是
   `0 < gap <= min(extrap_max_bracket_s, max_cross_gap_s) and drop >= drop_need_px`
   —— 我上一轮的实现**漏了 `drop >= drop_need_px` 这一条**，等于给拟合路径开了个后门；
   他们补上了，是对的。
2. **篮筐采样存全**：`HoopTrack.to_dict` 现在保留全部采样点 + 微秒时间小数 +
   `samples_complete` 标记。实测 nathan 的 `hoop.samples` 从 **17 → 81**（= votes），
   时间戳形如 `0.333747`。这正是我实测"16px 篮筐误差就能翻盘"的根源之一。

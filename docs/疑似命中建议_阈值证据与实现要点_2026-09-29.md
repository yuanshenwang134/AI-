# 疑似命中建议：阈值证据与实现要点（2026-09-29）

复核方定的下一步方向（原文要点）：

- **保留 0.5 秒实测连续性**：缺 0.53 秒即使只差 0.03 秒，也**不能**当作已经观察到穿筐；
- 单独处理"**筐上观测 → 短暂遮挡 → 筐内连续下降**"的证据形态：满足时给"**建议命中**"，
  附核对时间，**确认前不计分**；
- **不用**"首次筐下观测"重置命中窗口（否则可能让很晚出现的无关球重新获得判进机会）；
  应区分"接近篮筐"与"进入有效筐口区域"。

本文给出：① 该规则在六段既有 trace 上的**命中/误报统计**；② 阈值敏感性；
③ 现有链路盘点（哪些已经通、还差什么）；④ 实现后要用什么验收。

**注意**：这些都是**形态统计**（用同一次运行已选中的球/筐），不是判定结果，
也没有改任何代码或默认值。

## 二、阈值敏感性（横向容差是关键）

```
tol=0.5×筐宽  → game01 只报 16.48 一处；其余五段全 0        ← 精确
tol=0.75×筐宽 → game01 变成两处：11.28 与 16.48             ← 多报的 11.28 是【真未中】
tol=1.0 / 1.5 → 与 0.75 相同（仍是 11.28 + 16.48）
```

缺口上限在 0.6 / 0.8 / 1.0 秒之间**没有差别**（真例子的缺口是 0.53s）。
结论：**横向容差应取"真正的筐口"= 0.5×筐宽**（也就是球心必须落在筐口内），
放宽到 0.75×就会把一个真实未中报成疑似命中。

# 开源借鉴与投篮证据分级修正（2026-09-25）

## 阅读范围与取舍

参考仓库已下载在 `D:/dsh_folder/_refs/src/`，本轮直接阅读本地源码，没有重复下载、安装或运行第三方模型。

- `basketball-tracking/basketball/core.py` 的 `ball_state_counts_for_events`：按球状态来源决定能否参与事件判定。借鉴“观测与推算分开”的原则，独立修正本项目的证据传递；没有复制其跟踪器。
- `TrackNetV3/predict.py`：使用 InpaintNet 与缺失掩码补轨迹。有助于理解遮挡恢复，但补出的坐标不等于看到球穿筐。本轮没有接入模型，也没有篮球专用权重效果证据。
- `KaliCalib/modeling/example_camera_model.py`：标定需要成对的空间/图像点以及相机约束。不能仅凭篮筐已知高度，从一个球像素点唯一反算球的三维高度；本轮未引入这种伪高度判据。

## 已修改

1. `hoop.py`：空档插值标记为 `cross_interpolated`，趋势拟合继续标记 `cross_extrapolated`。两者均降低置信度，开关继续默认关闭。
2. 拟合分支仍须满足原有下落距离门槛（含米制尺度估计下限）及最大穿越时间，不得通过拟合绕过限制。米制尺度仍是图像比例估计，不是可靠的三维测量。
3. `sources.py`：向出手记录保留 evidence、crossing_t、suggested_made。推算结果的 made 留空，并标记 inferred_outcome / needs_review；统计中的视觉命中数不再把它们算作已确认命中。另记 inferred 数量。
4. `rules.py`：保留上游证据标签，避免进入最终出手与复核输出时丢失。没有独立结果证据时，推算建议最终仍为 unknown；独立的比分牌/穿筐证据仍可参与原有融合。
5. `HoopTrack.to_dict`：保存全部篮筐采样点和微秒级时间小数，增加 samples_complete 标记。旧文件丢掉的采样无法恢复；新文件也仍受坐标序列化精度等因素影响，不能承诺完全无损回放。输出体积会增加。

直接穿筐路径以及 hoopsight 薄筐亚像素出口容差未放宽。新的门槛检查只收紧可选拟合分支。

## 给外部复核的重点

默认配置下，核对现有四段素材是否保持既有结果。单独打开任一空档开关时，检查 raw_track 中 evidence / crossing_t / suggested_made、最终 unknown 和 needs_review 标签；这类候选不能仅凭推算变成已确认命中。独立比分牌或人工确认应单独说明来源。

后续真正提高召回，优先考察漏检恢复及动态篮筐定位；需要篮球数据与独立负例验证。nybo 的两个已知假进球和 nathan 的逐球对齐仍有价值，本轮没有替外部复核完成这些检查。

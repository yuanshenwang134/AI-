# 投篮切段与复核修正

本轮保留外部复检的长轨迹支持、反转速率门槛、篮筐漂移闸门及 cannot_judge。未改变穿筐判进、遮挡插值阈值，未运行模型或重跑视频。

## 改动

1. 弧线切段与投篮判断统一采用相对篮筐坐标，避免摇镜造成额外最低点。
2. 切段逐样本更新真正的极值，等反向移动累计到阈值再确认；缓慢运动与小抖动不会把切点推到错误位置。
3. 有明确穿越时刻的候选按穿越时刻去重，而不只比轨迹起点；相差不足 0.2 秒的穿越归为同一候选。这个启发式仍需真实快速补篮场景复检。
4. 没有人工时间戳时，评测脚本不再因为总数相同就宣称逐球对齐，也不输出对应的准确率。
5. 新增 scripts/export_shot_review.py，从既有 raw_track.json 导出候选表和空白人工真值表；可选 --clips 生成短片。不会覆盖已有输出目录，不预填人工判断。

## 验证

test_shot_visibility + test_shot_segmentation：18 项通过；test_plan_a：16 项通过。测试使用合成轨迹或既有数据结构，不证明真实视频召回率改善。

## 复检方式

候选表的 decision 填 shot / duplicate / not_shot / unclear。同一真实出手使用同一个 truth_id。真值表每球一行：truth_id、release_t（原视频出手秒数）、result（make / miss / unknown）、note。

必须通看完整原视频补上漏检；候选短片不能独立用于统计召回率。不要把模型结果复制为人工真值。对只有下降段的候选，candidate_t 只是可见轨迹起点，人工应找实际出手时间。

导出命令：
```
python scripts/export_shot_review.py --raw out/JOB/raw_track.json --out out/JOB/review_new --clips
```

本轮已从 out/eval_shots_vs_truth.json 所引用的四个旧任务导出表格到 out/shot_review_round2；这些是旧模型候选，不能当作本轮修正后结果。此目录没有生成视频短片，也没有填写人工真值。

优先复查 nathan 的额外出手是否为重复、反弹或传球。局部高频噪声被长时间均值稀释、真实补篮与反弹区分仍需进一步证据；本轮没有为追求数量接近人工而调整判进阈值。

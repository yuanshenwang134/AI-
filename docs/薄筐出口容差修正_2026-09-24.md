# 薄筐出口容差：修改与离线回放

## 修改

出口仍要求测到球在篮圈中心线下方。对尚未达到原出口线的中心候选，只容许 `min(0.5px, 0.1 × max(ry,1px))` 的差额，并要求横向在 `min(0.6,cross_inner) × rx` 内。完整链条仍经过原有几何检查、筐内证据帧检查及置信度过滤。使用该容差会写入 shot.note 与 spans.exit_tolerance_used。

配置为 `SightConfig.exit_pixel_tolerance=0.5`；设为 0 可恢复原出口规则。它是有上限的阈值容差，不是新获得的落网证据。球消失、仅到中心线、筐沿外侧经过都不会因此直接判进。`cross_inner` 与 `allow_hole_interpolation` 未改变。

外部建议 `max(ry,4~6px)` 会提高薄筐出口要求，不能修复该 0.16px 短缺，故未采用。

# 旧投篮引擎接入

来源：本项目旧版 HoopAI，恢复 bundle 的 HEAD `73792c6`。
scorer.py/detector.py 从恢复工程移入，包含 2026-09-27 预测点不建立出手、遮挡兜底只给建议的修正。
无需在运行时访问 `hoopai_from_bundle`；模型使用新版 API 已有权重路径。

stream.py 搬移逐帧选球、跳变拒绝、短时预测、篮筐筛选，增加切镜重置和全精度诊断记录。
模型使用旧版 640 输入、0.25 检测置信度和 0.5 NMS；不是把新版已筛选轨迹再喂回旧版。
adapter.py 转换为新版 Attempt，保留三态、出手时间、穿筐时间、推算建议与复核片段终点。

有标定时只投影出手人脚下；不把空中球直接投影为出手位置。不导入旧版的像素距离三分估算。
无法归队时不把命中加入任一队得分。出手候选与命中结果仍保留，附 team_unknown 标签。

默认关闭遮挡兜底、穿越起算实验和身份锁；这些配置保持旧基线，并非声称它们已解决比赛场景。
历史旧版的近筐传球误报、超时判未中和筐身份问题仍需真实视频回归。
逐帧记录在 raw_track.detections_meta.legacy_shots，game.json 仅保留精简的引擎配置与模型指纹。

`python scripts/replay_legacy_shots.py --raw <新任务/raw_track.json> --out <独立输出.json>`
只回放同次运行的球/筐/人观测；exact_match 检查与保存事件逐字段一致，不代表人工真值准确率。
